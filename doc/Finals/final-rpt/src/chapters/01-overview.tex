\section{项目概述与研发演进}\label{sec:overview}

\subsection{项目目标}

本项目面向竞业达指定 FPGA 平台，目标是在受限片上存储与逻辑资源条件下完成一款可综合、可验证、
可上板运行的 RISC-V 处理器。设计同时关注三类约束：指令及机器态控制流的正确性，顺序流水线在数据
相关、访存延迟和控制流重定向下的稳定运行，以及 FPGA 实现后的频率、资源与工作负载运行时间。
核心硬件以 SystemVerilog 作为综合与交付的 RTL 形式，工程使用 Chisel 辅助生成部分 SystemVerilog，
并为存储器、乘除法器等器件提供仿真模型与 Vivado IP 的一致接口。

\subsection{设计平台}

处理器目标器件为 Xilinx Kintex-7 XC7K325T-2FFG900，使用 Vivado 2024.2 完成综合、布局布线与
bitstream 生成。仿真侧使用 Verilator/C++ 周期级仿真与 Vivado Simulation；NEMU 作为指令级参考
模型，共享差分测试框架负责比较通用寄存器、PC 及相关体系结构状态。板级系统包含 IROM、DRAM、
计时器、LED、数码管与 UART 等资源，处理器通过统一地址映射访问。

\subsection{设计原则}

\begin{itemize}
  \item \textbf{顺序提交：}多周期运算、缓存命中或重定向均不得破坏程序顺序可见性。
  \item \textbf{显式握手：}流水级和多周期单元以 ready/valid 表达接受、保持和完成条件。
  \item \textbf{局部化关键路径：}按消费者类型分割结果、地址、分支和加速通路，减少宽选择器跨模块传播。
  \item \textbf{保守一致性：}缓存无法安全合并时使对应行失效，较新 store 优先于较早 load 回填。
  \item \textbf{测评可复现：}程序镜像、频率、实现报告与运行输出组成同一测评记录，避免跨口径比较。
\end{itemize}
