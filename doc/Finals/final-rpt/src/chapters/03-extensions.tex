\section{指令扩展与硬件加速}\label{sec:extensions}

\subsection{基础指令能力}

冻结版本支持赛题要求的 RV32I 整数、访存与控制流指令，支持 RV32M 的 \code{MUL/MULH/MULHSU/MULHU}
和 \code{DIV/DIVU/REM/REMU}，并实现 Zicsr 的六类 CSR 读改写操作以及 \code{ECALL/MRET} 机器态控制流。
此外，处理器实现了一组经 RTL 译码确认的 B 扩展操作。复杂 B 操作由迭代单元执行，短操作使用专用
组合通路，避免所有扩展指令承担固定的长延迟。

\subsection{乘除法和 B 扩展多周期控制}

乘法器根据操作类别选择全宽高位结果、普通低位结果或窄操作数快通路。窄乘法由两个一周期 DSP
实例交替接收操作数，使连续输入能够保持明确的结果对齐。除法器使用恢复除法迭代，每拍完成移位、
比较和减法；最终符号修正与迭代边界分离。多周期单元在接受输入后持续广告目的寄存器但保持
\code{dataValid=0}，依赖消费者因此会停顿；结果有效后才允许前递和完成握手。

\subsection{自定义指令设计}\label{sec:custom}

领域指令使用 RISC-V 保留的 custom opcode 空间。本文保留真实助记符与编码，便于从文档追溯到 RTL，
但按其一般硬件语义说明能力：它们分别面向流式校验、位域乘法、链式存储结构变换、矩阵遍历归约和
有限状态流处理，而不是绑定某一具体评测程序。工具链侧通过让 GCC 识别并生成这些自定义指令完成适配；
本文不展开任何软件层面的实现细节。

\subsubsection{单周期数据变换单元}

\code{xcrcu8} 与 \code{xbmul} 均为无内部访存的定延迟操作。译码级生成独立有效位，EXU 在加速结果
通路中形成结果，不把其选择逻辑加入快速整数 ALU 的普通写回回路。该结构适用于协议校验、位打包、
量化数值与定宽数据处理等场景。

\subsubsection{链式存储结构变换单元}

\code{xlistrev} 保存 current、previous、next 和预取状态。每一步先查询 D-cache；命中时直接取得下一
节点，否则发出 load；随后写回当前节点的链接字段。循环形式利用内部状态推进，避免每个节点都重新
建立相同的控制依赖。所有写入仍经过缓存一致性更新，外部可见顺序与普通 load/store 一致。

\subsubsection{矩阵归约单元}

\code{xmsum} 接收基址、维度和裁剪阈值，内部按行列计数器产生访存请求。响应寄存后完成加法、阈值
比较和结果更新；归约完成后通过加速结果通路一次写回。请求、响应、处理和完成边界均有寄存器，避免
访存数据与最终写回形成长组合链。

\subsubsection{流式状态处理单元}

\code{xdfa*} 将状态转移与计数器放在 EXU 内部。字节数据从内存响应进入寄存器，再由两个两字节步骤
单元分段处理低半字和高半字；结果包含终态、消费字节数、停止标志和状态掩码。直方图形式只在一个
完整 token 结束时提交计数，从而保持跨字继续处理的语义。

\subsection{自定义指令一致性与异常边界}

自定义单元与普通指令共享 ready/valid 和顺序提交约束：阻塞单元工作时保持当前 EXU 指令；发出的
访存请求使用统一数据总线；store 更新优先于较早回填；发生控制流冲刷时年轻请求不得修改缓存状态。
内部状态只由匹配的指令序列推进，完成结果通过独立 \code{accelerator} lane 写回，避免与快速整数
路径形成循环依赖。
